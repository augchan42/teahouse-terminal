5-minute skit breakdown:
- Total messages: 15-20 (down from 20-30)
- Messages per minute: 3-4 (down from 6-8)
- Words per message: ~30
- Total words: ~450-600

Phase timing:
- Intro: 75 seconds (2-3 messages)
- Development: 150 seconds (6-8 messages)
- Climax: 90 seconds (4-5 messages)
- Resolution: 45 seconds (2-3 messages)

Reading time required:
450-600 words ÷ 200 words per minute = 2.25-3 minutes actual reading time

interface MessagePacing {
    messagesPerMinute: number;     // Target: 6-8 messages/minute
    wordsPerMessage: number;       // Target: 25-35 words
    totalWordsPerMinute: number;   // ~175-280 words
    readingTimeRequired: number;   // ~1-1.5 minutes of reading per minute of generation
}
